# Portfólio | Willian Braga

Portfólio pessoal desenvolvido para apresentar minha formação, habilidades, interesses e alguns projetos realizados durante meus estudos na área de tecnologia.

## 📌 Sobre o projeto

O site reúne informações acadêmicas e profissionais em páginas HTML estilizadas com CSS. O layout utiliza uma paleta de azul-marinho, tons claros e verde-água, com ajustes para melhorar a leitura em diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5** para estruturar as páginas.
- **CSS3** para cores, tipografia, navegação, cartões, tabela de habilidades e adaptação para telas menores.

## 📄 Conteúdo do site

- **Início e formação:** apresentação pessoal e formação acadêmica.
- **Habilidades:** habilidades gerais, banco de dados e linguagens de programação.
- **Interesses:** objetivos de aprendizado e desenvolvimento profissional.
- **Projetos:** links para os repositórios do Academy Help Desk e do site de súmula de xadrez.
- **Sobre mim e contatos:** informações adicionais e formas de contato.

## 🚀 Como executar

O projeto não precisa de instalação de dependências ou processo de compilação.

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confirme se os arquivos HTML, o `style.css` e a pasta `img/` estão nos locais esperados.
4. Abra `willian_index.html` no navegador. Se preferir, utilize a extensão **Live Server** do VS Code para visualizar as alterações enquanto desenvolve.
